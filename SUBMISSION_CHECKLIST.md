- [ ] Extract the ZIP and open the folder in VS Code.
- [ ] Install dependencies using `pip install -r requirements.txt`.
- [ ] Start the app with `streamlit run app.py`.
- [ ] Add a sample lead and verify it remains after a refresh.
- [ ] Generate and save an outreach draft.
- [ ] Test status updates and CSV downloads.
- [ ] Run `pytest -q`.
- [ ] Take genuine screenshots of the running application.
- [ ] Review README and report for accuracy.
- [ ] Remove any real credentials and personal data before sharing.
- [ ] Zip the complete project folder for submission.
